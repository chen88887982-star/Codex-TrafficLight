# 普通用户快速开始

Codex Traffic Light 把 Codex 的状态、任务和额度显示在 Windows 桌面，也提供浏览器看板。状态服务支持 Windows / macOS；桌面皮肤需要 Windows + Rainmeter。项目使用 [MIT 许可证](../LICENSE)。

项目分享地址：<https://github.com/chen88887982-star/Codex-TrafficLight>。GitHub 页面点击 **Code → Download ZIP**，完整解压到固定文件夹再操作。

## 先选你的设备组合

| 使用方式 | 服务安装位置 | 皮肤安装位置 |
|---|---|---|
| 同一台 Windows | 运行 Codex 的 Windows | 同一台 Windows |
| Mac + Windows | 运行 Codex 的 Mac | Windows |
| 两台 Windows | 运行 Codex 的 A 电脑 | 显示状态的 B 电脑 |

服务电脑准备 Python 3.10+ 和已安装、登录的 Codex；在使用 Codex 的同一用户下启动服务。皮肤电脑安装并运行 [Rainmeter](https://www.rainmeter.net/)。普通运行只需 Python 标准库，无需安装开发依赖。

## 同机 Windows

1. 双击 `win\codex_status_server\启动状态服务.cmd`，服务在后台运行。
2. 浏览器打开 `http://127.0.0.1:8767/health`，确认本项目的接口可达；有异常时查看具体健康分项。
3. 双击根目录 `install-rainmeter-skin.cmd`。
4. Rainmeter 管理器点击“刷新全部”，加载 `CodexTrafficLight\CodexTrafficLight.ini`。
5. 右键皮肤 → 设置，读取地址保持 `http://127.0.0.1:8767/rainmeter`。

同机访问无需令牌。点击皮肤标题，或在浏览器打开 `http://127.0.0.1:8767/` 查看完整看板。

## 跨电脑：先在服务电脑生成令牌

0.5.1 起，局域网的数据读取与偏好操作都需要服务访问令牌。在项目根目录打开终端，执行对应命令：

Windows：

```powershell
python common/configure_access.py
```

Mac：

```bash
python3 common/configure_access.py
```

命令生成私有 `status-auth.json` 并显示令牌，保留已有配置和有效令牌，不重置通知等设置。原文件格式有误时会停止并保留原文件。此文件已被 Git 忽略；令牌只用于自己的设备，不放到公开截图、社交媒体或仓库里。

接着启动服务；如果服务之前已经运行，先用本项目停止脚本停止，再用原入口启动。环境变量 `STATUS_ACCESS_TOKEN` 若已设置，会优先于配置文件，请在客户端使用同一个令牌。

## Codex 在另一台 Windows

在服务电脑的项目根目录，用 PowerShell 执行：

```powershell
& '.\win\codex_status_server\启动状态服务.cmd' lan
```

先在服务电脑浏览器检查 `http://127.0.0.1:8767/health`。再打开命令提示符运行 `ipconfig`，找到当前联网网卡的 IPv4 地址。

## Codex 在 Mac

先完成上面的令牌配置。打开 Mac 终端，进入 `mac/codex_status_server`。示例中的 `/项目实际路径` 要替换为解压后的项目根目录：

```bash
cd "/项目实际路径/mac/codex_status_server"
chmod +x 启动状态服务.command
./启动状态服务.command
```

服务后台运行，重复启动会复用同版本服务。首次默认监听局域网；后续沿用已有启动配置。曾配置为仅本机监听时，显式使用 `CODEX_STATUS_HOST=0.0.0.0 ./启动状态服务.command` 恢复局域网监听。

先在 Mac 浏览器检查 `http://127.0.0.1:8767/health`。在“系统设置 → 网络”里查看当前 Wi-Fi 或以太网的 IP 地址。只有 Mac 时，也能在本机打开 `http://127.0.0.1:8767/` 使用浏览器看板。

## Windows 安装皮肤并连接服务电脑

1. 在 Windows 下载并解压同一版本的项目，双击根目录 `install-rainmeter-skin.cmd`。
2. Rainmeter 刷新全部，加载 `CodexTrafficLight\CodexTrafficLight.ini`。
3. 右键皮肤 → 设置，填写带令牌的读取地址：

```text
http://服务电脑IP:8767/rainmeter?token=你的令牌
```

4. 检查远程健康接口时，也需要携带令牌：

```text
http://服务电脑IP:8767/health?token=你的令牌
```

5. 浏览器看板打开 `http://服务电脑IP:8767/`，点击“访问设置”，输入同一个令牌再连接。看板将令牌保存在当前标签页的 sessionStorage，用 Authorization 请求头发送。

地址中的 IP 来自服务电脑。`127.0.0.1` 始终指当前设备，不能用它连接另一台 Mac 或 Windows。跨电脑需要设备间网络互通、服务正确监听、对应端口可访问。

## 日常使用与排查

- 红灯配合文字区分运行中和异常；黄灯等待确认；绿灯表示明确完成，默认 45 秒后回到空闲；灰灯配合文字区分空闲和离线。
- 额度标注来源和更新时间。窗口以账户返回为准；日志快照是降级来源，账户百分比差值不能归因到单个任务。
- “忽略本轮”只影响本工具展示，Codex 任务继续运行。
- 显示 403：检查服务电脑是否已生成令牌、重启服务，以及客户端使用的令牌是否一致。
- 同机能看、跨电脑不通：核对服务 IP、Windows `lan` 模式和网络连通性。
- 升级时重新安装皮肤并重启服务，避免旧后端与新皮肤混用。
- 停止、登录自启动、通知、端口与体检的完整说明见 [项目 README](../README.md)、[Windows 服务](../win/codex_status_server/README.md)、[Mac 服务](../mac/codex_status_server/README.md)。
